# Medmac Work — شغل مدماك

A scroll-driven walkthrough of everything built for **Medmac Kuwait Co. For General Trading
& Contracting**. Arabic-first with an English toggle.

Each chapter opens with the payoff — what it saves, stops or earns — then the camera moves
across a real screenshot of the working software, beat by beat, and closes with written
documentation for the same subject. Picture and prose, so nobody has to pick one.

- **Live:** https://mohamed3042.github.io/medmac-work/
- **Deep link to a scroll position:** append `?y=<pixels>`

Static site: one HTML file, no build step, no dependencies. Images are real captures of the
installed software, not mockups.
